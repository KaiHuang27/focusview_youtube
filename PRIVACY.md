# Privacy Policy

FocusView – Zoom, Rotate & Mirror for YouTube does not collect, store, sell, share, or transmit any personal data.

The extension only runs on YouTube pages to provide video zoom, rotation, and mirror controls inside the YouTube player.

This extension does not:

- collect personal information
- track user activity
- use cookies
- access browsing history
- access account information
- store user data
- send data to external servers
- use analytics or advertising trackers

All video transform controls are applied locally in the browser. No user data leaves the device.

If you have any questions about this privacy policy, please contact the developer.
