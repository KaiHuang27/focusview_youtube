FocusView의 간결하고 세련된 컨트롤로 YouTube 동영상을 손쉽게 확대·축소하고, 회전하거나 좌우로 반전하세요. 화면을 가까이 당겨 세부 장면까지 즐겨 보세요.

기능:
• 마우스 휠을 스크롤하여 동영상을 100%~500%로 확대·축소
• 동영상을 90°, 180°, 270° 회전
• 동영상을 좌우로 반전하여 거울처럼 표시
• Alt + Shift + Z (Mac: Option + Shift + Z)를 눌러 확대 모드 켜기 또는 끄기

이럴 때 사용해 보세요:
• 화면 크기에 맞춰 동영상의 검은 여백을 없애고 싶을 때
• 콘서트와 실시간 스트리밍을 볼 때
• 스포츠 영상을 볼 때
• 강의와 튜토리얼을 볼 때
• 동영상을 더 가까이 보고 싶을 때

개인정보 보호 및 권한:
FocusView는 데이터를 수집하거나 사용자를 추적하지 않으며, 외부 서버로 어떠한 데이터도 전송하지 않습니다. 모든 화면 조정은 사용자의 브라우저 내에서 처리됩니다.
